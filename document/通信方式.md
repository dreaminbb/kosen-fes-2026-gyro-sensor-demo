# BLE・USB通信とゲーム開始

MG24（Peripheral）とXIAO ESP32-C6（Central）はBLE GATTで接続する。
GodotはC6のUSBシリアルを `arduino-cli monitor`（115200 baud）経由で読み書きする。

- Service UUID: `4880c12c-fdcb-4077-8920-a450d7f9b907`
- Data Characteristic UUID: `fec26ec4-6d71-4442-9f81-55bc21d658d6`
- MG24 → C6: Notification。C6 → MG24: Write Without Response。
- LF区切りの行。BLE通知の分割はC6で再構成し、MG24の行に `RX,` を付けてUSBへ渡す。
- センサーは100 Hz。`DATA,elapsedUs,accelX,accelY,accelZ,gyroX,gyroY,gyroZ`。
  時刻はμs、加速度はg、角速度は度/秒。

## コマンド

| Godot → C6 → MG24 | MG24の応答 | 動作 |
| --- | --- | --- |
| `CMD,START` | `ACK,START` | センサー読み出しとDATA通知を再開 |
| `CMD,STOP` | `ACK,STOP` | 読み出しとDATA通知を停止。C6は応答確認後にBLEを切断し、探索を休止 |
| `CMD,RESET` | `ACK,RESET` | センサーの時刻基準を戻して再開。Godotはゲームを初期化して玉を上空に固定 |

STOP後もMG24はBLEの制御処理と接続用アドバタイズを継続し、STOP状態を再接続に引き継ぐ。
USBシリアルは切断しない。C6はBLE切断中もコマンドを受け付け、最新の希望状態を保持する。
START/STOP/RESETはACKまで500 ms間隔で再送し、2秒応答がなければ再接続する。
START後のDATAが2秒止まった場合も再接続する。再接続時にゲームのRESETは行わない。

## C6 → Godotのイベント

| USB行 | 意味 |
| --- | --- |
| `RX,GAMERESET` | 物理ボタンの押下。GATT接続と通知購読が完了してから送る |
| `GAME,BUTTON_PENDING` | C6が物理押下を保持してBLE接続中。Godotは状況だけ表示し、GAMERESETを待つ |
| `GAME,WAKING` | GodotからのSTART要求を受け付けた。押下としては扱わない |
| `GAME,READY` | START要求に対してMG24のACKと、その後の数値が有限かつ加速度ベクトルがゼロでないDATAを確認した |
| `GAME,SLEEPING` | MG24のSTOP応答を確認し、C6がBLE休止状態に入った |

物理ボタンはGPIO1（D1）、互換用GPIO2のHIGH入力。内部プルダウン、100 msデバウンス、
立ち上がりで1イベント。`pollGameResetPin()` → `requestGameButton()` → GATT接続・通知購読 →
`RX,GAMERESET` → Godotの `_on_game_button_pressed()` が物理ボタンの経路となる。
C6のUSB入力 `GAMERESET` / `CMD,GAMERESET` は、この経路を確認するための疑似入力。
接続状況通知だけでゲームを開始することはない。

## ゲームの状態

起動時は玉をSTARTの床上1.8 mに固定し、「ボタンを押してスタート」と表示する。
最初の押下で記録を初期化して「もう一度押して再開」へ切り替え、次の押下で復帰を要求する。
プレイ中の押下も同じ待機状態へ戻る。待機中は台を水平に固定し、計時・進捗・落下判定を止める。

Godotは待機に入ってから `mg24_stop_delay_seconds`（既定180秒）でSTOPを送る。
再開ボタンが先に押された場合は停止タイマーを破棄する。センサーの静止判定は使用しない。
手動のSTOPコマンドだけは待たずに通信を停止する。

休止中の再開は、C6の探索 → GATT接続 → 通知購読 → START → ACK → 新しいDATA →
`GAME,READY` の順。GodotはREADYと有効な新しい姿勢データが揃うまで、玉を固定したまま
中央に接続状況を表示する。準備が整ったらぼかしを消して玉を落とし、計時を開始する。
復帰処理中の追加押下は無視する。
