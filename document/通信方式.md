# PCとの通信方式

## 接続方式

Seeed Studio XIAO MG24 (Sense) を BLE 5.3 対応の周辺機器として動かし、Godotを実行するPCから接続する。ファームウェアは KosenBall という名前で広告し、Godot側はGDBLE GDExtensionで検索、接続、GATT通知購読を行う。Wi-Fi APとUDPソケットは使用しない。

Godot用拡張は 高専祭玉転がし/addons/gdble に含めてある。配布元とライセンスは UPSTREAM.md と LICENSE を参照。

## GATT仕様

- Service UUID: 4880c12c-fdcb-4077-8920-a450d7f9b907
- Data Characteristic UUID: fec26ec4-6d71-4442-9f81-55bc21d658d6
- MG24からPC: Notification
- PCからMG24: Write Without Response
- 1行をLFで区切る。BLEパケットが分割されても受信側で行を再構成する。

テレメトリー形式は DATA,elapsedMs,accelX,accelY,accelZ,gyroX,gyroY,gyroZ。elapsedMsは送信開始からの経過ミリ秒、加速度はg、角速度は度/秒。現在のファームウェアは sample.h のテスト列を100 ms間隔で送信する。

Godotからは CMD,START、CMD,STOP、CMD,RESET を送れる。MG24は ACK,START、ACK,STOP、ACK,RESET で応答する。RESETはテスト列とGodotの姿勢表示を先頭に戻す。

## ビルド設定

Arduino CLIではBLE (Silabs)スタックを選択する。XIAO MG24の既定スタック（Matter）のままではこのGATTファームウェアをビルドできない。

ビルドコマンド:

    arduino-cli compile --fqbn "SiliconLabs:silabs:xiao_mg24:protocol_stack=ble_silabs" .

Godotプロジェクトは 高専祭玉転がし/project.godot を開いて実行する。OS側でGodotのBluetooth利用を許可する。
