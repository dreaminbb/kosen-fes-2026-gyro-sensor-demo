# PCとの通信方式

## 接続方式

Seeed Studio XIAO MG24 (Sense) と XIAO ESP32-C6 をBLE 5 GATTで接続し、C6をUSBでPCに接続する。MG24は `KosenBall` としてPeripheral動作し、C6がCentralとして通知を受信する。GodotはC6のUSBシリアルを115200 baudで開き、センサーデータを表示してコマンドを送る。Wi-Fi APとUDPソケットは使わない。

## GATT仕様

- Service UUID: 4880c12c-fdcb-4077-8920-a450d7f9b907
- Data Characteristic UUID: fec26ec4-6d71-4442-9f81-55bc21d658d6
- MG24からPC: Notification
- PCからMG24: Write Without Response
- 1行をLFで区切る。BLEパケットが分割されても受信側で行を再構成する。

テレメトリー形式は DATA,elapsedMs,accelX,accelY,accelZ,gyroX,gyroY,gyroZ。elapsedMsは送信開始からの経過ミリ秒、加速度はg、角速度は度/秒。現在のファームウェアは sample.h のテスト列を100 ms間隔で送信する。

Godotからは `CMD,START`、`CMD,STOP`、`CMD,RESET` を送れる。C6がBLE Write Without ResponseでMG24へ転送し、MG24は `ACK,START`、`ACK,STOP`、`ACK,RESET` で応答する。RESETはテスト列とGodotの姿勢表示を先頭に戻す。

## ビルド設定

Arduino CLIではBLE (Silabs)スタックを選択する。XIAO MG24の既定スタック（Matter）のままではこのGATTファームウェアをビルドできない。

ビルドコマンド:

    arduino-cli compile --fqbn "SiliconLabs:silabs:xiao_mg24:protocol_stack=ble_silabs" .

Godotプロジェクトは `高専祭玉転がし/project.godot` を開いて実行する。Godot起動時にC6のUSBシリアルポートを探し、見つからない場合は画面のポート欄へ入力する。Godotは `arduino-cli monitor` を起動するため、Arduino CLIがPATHにあり、ポートを他のシリアルモニターが使用していないこと。

## MG24–ESP32-C6間の低遅延双方向通信

MG24とC6の間では、BLE 5の接続型GATTを使う。MG24がPeripheral、C6がCentralとなり、同じData CharacteristicをMG24→C6のNotificationとC6→MG24のWrite Without Responseに共用する。ESP-NOWはMG24の無線方式ではないため、この2種類のチップを直接つなぐ用途には使わない。

MG24が最短の接続間隔7.5 ms（BLE単位6）を要求し、C6が受け入れる。実際に適用された間隔はMG24の `BLE interval:` ログで確認する。MTU 247を使い、サンプル1行を複数通知に分割せず送る。通知はセンサーサンプル間隔の100 msごとに発生するため、この設定は接続待ち時間を短くするが、サンプル周期自体は変えない。

C6 Centralをコンパイルする:

    bash tools/compile_c6_ble.sh

このスクリプトはArduino-ESP32のNimBLE `BLEClient` が接続直後のMTU交換で`BLE_HS_EALREADY`を受けた際、接続を失敗扱いして待ち続ける問題を避けるため、インストール済みコアの`BLEClient.cpp`に限定パッチを適用する。ソースの想定箇所が見つからないコアでは変更せず停止する。

C6は接続後に `CMD,RESET` を自動送信し、MG24からの `ACK,RESET` と `DATA,...` を `printf` でUSBシリアルへ出力する。Godotは `arduino-cli monitor` の標準入出力を読み書きし、同じ `CMD,START`、`CMD,STOP`、`CMD,RESET` をC6へ送る。手動で試す場合はGodotを閉じ、C6のシリアルモニターからこれらのコマンドを1行ずつ送る。

## ESP-NOW検証ファームウェア

XIAO MG24にはWi-Fiがなく、ESP-NOWには参加できない。そのため、MG24の現在のBLEファームウェアはESP-NOWへ切り替えられない。ESP-NOWで運用する場合は送信側もESP32系の基板にするか、MG24とESP32送信ブリッジをUART接続する必要がある。

検証用に `espnow/c6_receiver` はXIAO ESP32C6で受信し、`espnow/esp32_test_sender` はESP32系基板から100 ms間隔でサンプルパケットをブロードキャストする。両方ともチャンネル1を使う。C6は受信行をUSBシリアルへ `DATA,...` 形式で出力する。ESP-NOW検証ファームウェアは現在のGodot BLEブリッジとは連動していない。

受信機をコンパイルする:

    bash tools/compile_espnow_c6.sh

テスト送信機をコンパイルする:

    arduino-cli compile --fqbn esp32:esp32:XIAO_ESP32C6 espnow/esp32_test_sender

実機試験にはESP32系の送信機とXIAO ESP32C6受信機の2台が必要。MG24だけでは送信試験できない。
